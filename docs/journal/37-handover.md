## The test of a handover 🇵🇱 Test przekazania

Open the README as someone who joins next month. Can they: run it
(`Getting started`), use it (`Commands in Discord`), change it (`Working as
a team of two`, `docs/architecture.md`), deploy it (`docs/deploy.md`), and
know what it cannot do (`Known limitations`)? Each question has one section.

🇵🇱 _Otwórz README jak ktoś, kto dołączy za miesiąc. Czy umie: uruchomić (`Od czego zacząć`), użyć (`Komendy na Discordzie`), zmienić (`Praca we dwóch`, architektura), wdrożyć (`docs/pl/deploy.md`) i wie, czego bot nie potrafi (`Znane ograniczenia`)? Każde pytanie ma jedną sekcję._
