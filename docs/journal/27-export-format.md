# #27 Choose the export format for the internship diary

Decided in the issue comment: Markdown, every working day visible, weekends
only when reported, header and footer with totals. `docs/export-sample.md` is
the target that #29 must reproduce byte for byte.

## Why hand-write the sample first 🇵🇱 Dlaczego próbka ręcznie, najpierw

Writing the file by hand is the cheapest way to look at the format with the
eyes of the person who will read it. The code in #29 then has a fixed goal
and a snapshot test, instead of a format that drifts while it is written.

🇵🇱 _Napisanie pliku ręcznie to najtańszy sposób, żeby spojrzeć na format oczami osoby, która będzie go czytać. Kod w #29 ma wtedy stały cel i test porównujący, zamiast formatu, który dryfuje w trakcie pisania._
